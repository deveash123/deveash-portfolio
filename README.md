# Deveash G. — Portfolio

An editorial portfolio for **Deveash G.** — AI & Tech Builder · Game Developer · App Developer,
Chennai, Tamil Nadu, India.

Built as a static single-page app: **Vite 8 · React 19 · TypeScript 7 · Tailwind CSS 4 · framer-motion 14**.

---

## Quick start

```bash
npm install          # restores node_modules (not included in this archive)
npm run dev          # http://localhost:5173
```

```bash
npm run build        # typecheck + production build into dist/
npm run preview      # serve the built site
npm test             # 15 content tests
npm run typecheck    # tsc only
```

## Adding your hero photo

The site ships with a **drawn placeholder silhouette**. To use your real photo:

1. Save it as **`assets/hero.png`**
2. Run `npm run portrait`

That white-keys the background out into a genuine transparent PNG at
`public/portrait.png`. It works because the source is a subject on a flat white
studio background — the pass ramps alpha between luminance 222 and 248, so hair
edges stay soft instead of shredding.

Then regenerate the social card so your face is in it too:

```bash
npm run build
npm run preview                      # in one shell
npm run og -- http://localhost:4173  # in another
```

> Both of those steps drive a real browser, so they need **Playwright + Chrome**.
> Neither is a project dependency, and the build is designed to survive without
> them: `npm run portrait` writes a blank stand-in and warns loudly rather than
> failing. Set `CHROME_PATH` if Chrome is installed somewhere non-standard, or
> install it locally with `npm i -D playwright-core`.

## What is generated, and why

These files are **produced by scripts, not hand-made**, so they cannot drift out of
sync with the site's own data. They are regenerated automatically on `npm run build`
via the `prebuild` hook.

| File | Generated by | From |
|---|---|---|
| `public/qr-portfolio.png` | `npm run assets` | `site.portfolio` in `src/data/site.ts` |
| `public/favicon.svg` | `npm run assets` | `site.initials` |
| `public/portrait.png` | `npm run portrait` | `assets/hero.png`, or a placeholder |
| `public/og-card.jpg` | `npm run og` | the **built** CSS + real self-hosted fonts |

`npm run verify:qr` decodes the QR with an independent decoder (jsQR) and asserts it
resolves to `site.portfolio` — so the address printed next to the code and the code
itself can never disagree.

> The social card is rendered by a real browser against the built CSS, because
> System.Drawing/GDI+ cannot load the self-hosted `.woff2` faces and would silently
> render the display word in a fallback font.

## Two content rules this project enforces

The design reference contained invented claims, so they are **deliberately not
reproduced**, and `src/tests/content.test.ts` fails the build if they creep back in:

1. **No fabricated testimonials.** The reference's "What Clients Say" band named three
   clients with job titles. There are none. Those slots carry your own "What I enjoy
   building" and "My direction" copy instead.
2. **No invented skill percentages.** The reference showed 95% / 90% / 85%. Those are
   fabricated precision. Skills use a four-step ordinal track with your own word beside
   it — C++ reads **Learning**, backend development reads **In progress**.

Project covers are **generated schematics**, not fake screenshots, and every project
detail page states plainly that no capture exists yet. A test asserts
`screenshot` and `demoVideo` stay `null`.

## Project structure

```
src/
  index.css            design tokens + every bespoke component class
  main.tsx             font imports, router mount
  App.tsx              routes, one <Suspense>, page transition, focus reset
  data/
    site.ts            identity, links, availability, education, copy
    portfolio.ts       projects, honest skill levels, direction
  components/
    Hero.tsx           name, role, portrait + clay disc, rotating SVG seal
    EdgeRails.tsx      the fixed vertical rail text down each side
    MegaWord (in css)  the full-bleed cropped display word
    EditorialCursor.tsx  ink/clay cursor, fine pointers only
    Meter.tsx          the four-step honesty scale
    ProjectCover.tsx   generated schematic covers
    ...plus header, footer, contact list, reveals, skeleton
  pages/               Home, Work, ProjectDetail, About, Direction, Contact, 404
scripts/
  make-assets.mjs      QR + favicon
  make-portrait.mjs    white-key cutout
  make-og.mjs          1200x630 social card
  verify-qr.mjs        decode + assert the QR
```

## Deployment

`vercel.json` contains the SPA rewrite — **without it, `/work/chatflow` 404s on
refresh**. Deploying to a new host: publish the `dist/` folder after `npm run build`
and configure the same rewrite.

## Design tokens

| Token | Value | Contrast |
|---|---|---|
| `paper` | `#f2eee6` | the warm off-white ground |
| `ink` | `#14120f` | 15.6:1 on paper |
| `ink-soft` | `#4a443c` | 8.4:1 on paper |
| `ink-faint` | `#7a736a` | 4.6:1 — large text / meta only |
| `clay` | `#b24a2c` | 5.4:1 on paper — the single accent |
| `clay-deep` | `#8e3a20` | 7.1:1 on paper |

Fonts are **self-hosted** (Anton, Playfair Display, Manrope Variable, Allura), so
there are no third-party font requests at runtime.
